Free tide widget for your website

Show today’s tide times on your own website — for any of our 12,000+ stations worldwide. Pick a location below, choose how many days to display, and copy two lines of HTML. The widget updates itself every day, is free to use, and only asks that the small attribution link stays visible.

1. Choose a location

With coordinates the widget automatically shows the nearest tide station — useful for beaches or anchorages that aren’t in the list.

Paste this where the widget should appear. It adapts to your page, inherits nothing, and you can style it with CSS (see below). Several widgets on one page work fine — the script line is only needed once.

Customising the widget with CSS

  

    The script embed renders plain HTML inside your page, so your own
    stylesheet can override anything. All elements carry prefixed class
    names; target them below .tide-widget in your CSS:
  

  

    
ClassElement

    
.tide-widgetOuter container (border, width, font)

    
.tw-headerHeader bar with the station name

    
.tw-dayOne day’s block

    
.tw-dateDate heading of a day

    
.tw-tableTable of tide events

    
.tw-icon, .tw-type, .tw-time, .tw-heightCells: icon, High/Low label, time, height

    
.tw-footerAttribution footer

  

  

    Example — a wider widget with your brand colour in the header:
  

  

    
<style>
  .tide-widget { max-width: 100%; }
  .tide-widget .tw-header { background: #234e70; }
</style>
